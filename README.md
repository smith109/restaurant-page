# Restaurant Page

This is the restaurant page project from the Odin Project. The purpose of this project was to practice using Webpack to combine multiple project files into a bundled JavaScript file containing all necessary code. The project also gave me a chance to review the following concepts: 

- ES6 Modules (ESM)
- Exports / Imports
- Building a dependency graph starting with an entry point
- Using JavaScript bundlers such as Webpack
- Using DOM manipulation to dynamically create HTML elements
